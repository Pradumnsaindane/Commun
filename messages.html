Hey team, I just benchmarked the new zero-copy ring buffer with AVX-512 SIMD vector instructions against the baseline channel queue. Here is the micro-benchmark function in Rust:
ring_buffer_simd.rs 
pub unsafe fn process_quantized_batch(input: *const f32, len: usize) -> f32 {
    use std::arch::x86_64::*;
    let mut sum_vec = _mm512_setzero_ps();
    for i in (0..len).step_by(16) {
        let chunk = _mm512_loadu_ps(input.add(i));
        sum_vec = _mm512_add_ps(sum_vec, chunk);
    }
    _mm512_reduce_add_ps(sum_vec)
}
